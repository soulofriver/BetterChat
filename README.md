# ChatGPT GUI Application (Tkinter + OpenAI)

This is a simple chatbot application built using Python's `tkinter` for the graphical user interface (GUI) and OpenAI's GPT model for generating responses.

## 💡 Features

- User-friendly GUI built with Tkinter
- Real-time interaction with OpenAI's GPT-3.5 model
- Simple and clean codebase
- Error handling for common API issues

## 📦 Requirements

Make sure you have the following installed:

- Python 3.7+
- `openai` Python package
- Internet connection

You can install the OpenAI package via pip:

```bash
pip install openai
